Claude Code Mods: User Guide

An unofficial community guide · Version as at 05/11/2026

Summary

What is Claude Code? Claude working directly inside a folder on your computer. Unlike a normal chat, it can read and change your files, run commands and carry out multi-step jobs, and it can hand parts of the work to helper agents (subagents). How to open it: in the Claude desktop app, use the Code tab and pick a folder, or type claude in a terminal. Why use it over standard chat: it works on your real files instead of pasted text, it finishes whole tasks rather than single answers, and it can be extended with add-ons such as the mods below.

Installation

The mods are published as one plugin marketplace on GitHub. You need Claude Code.

1. Add the marketplace

/plugin marketplace add mpchristensen11986-ux/my-claude-mods

2. Install a mod

/plugin install decision-support@my-claude-mods

Names: subagent-advisor, decision-support, side-chat-advisor, long-session-kit, savvy-progress, ribbon-wdc, commands-pane.

3. Reload

Run /reload-plugins, or start a new Claude Code session.

Change, update or remove

claude plugin configure decision-support@my-claude-mods
claude plugin update decision-support@my-claude-mods
claude plugin uninstall decision-support@my-claude-mods
claude plugin list

Effort Optimizer

Not part of this repository. Get it from its author: Ben AI's Claude Effort Optimizer.

NOTE: Install ribbon-wdc or the original Ribbon, not both.
WARNING: Mods are not sandboxed and run with the same access as Claude Code. Read the source of any mod before you install it.

Subagent Advisor

PurposeUse a subagent for a side task where you need the result but not the process or the reasoning, so the main conversation stays efficient. Or run several tasks in parallel from the same place.

When it appears

  • Before Claude starts a prompt that sweeps many files, lists several independent parts, or asks for long research or a big review.
  • As a toast after about 10 file reads or searches in one turn.

Your answers

  • Use subagents or Continue as normal.
  • Auto: always use subagents or Auto: never ask again.

After you choose subagents

When the job finishes, the Agents panel opens by itself (it comes from the Savvy Progress mod) so you can see what the subagents did, and the background tasks view opens too if your session has one. Switch this off with /subagent-advisor views off.

Try it

audit every file in this folder

Commands

/subagent-advisor status
/subagent-advisor mode ask
/subagent-advisor mode off
/subagent-advisor views on | off

Other modes: auto-delegate, auto-continue. mode ask undoes an Auto answer.

Decision Support

PurposeGet a second opinion from a stronger model before you commit to a high-stakes call, such as a security, contract, commercial or design decision. It reminds you to ask, so you do not have to remember.

When it appears

  • Your prompt looks like a decision, a risky action, a long plan, or asks for a second opinion.
  • Claude itself asks you a clickable question or ends by offering options.
  • Right after you approve a plan, or after repeated failed steps.

Your answers

  • Use /advisor with <model>: it switches the advisor, or shows the exact command to type if it cannot.
  • Continue without advisor, or an Auto option.

Suggested models (editable)

Deep claude-fable-5-1, standard claude-opus-5-5, quick claude-haiku-5-5.

Try it

Should we use n8n or Power Automate for the contract notice workflows? Compare the risks.

Commands

/decision-support status
/decision-support mode ask | auto-suggest | off

It never sends a prompt for you and never edits your settings file.

Effort Optimizer

PurposeMatch how hard Claude thinks to the job in front of it. Quick tasks are not over-thought, and work where a hidden mistake would cost money, a client or trust gets more care, without you having to remember to change the setting.

How it decides

Before Claude starts, a short check reads your prompt and asks four questions in order, stopping at the first yes:

  1. A back-and-forth or simple task? Low.
  2. Would a hidden mistake cost money, a client or trust? High.
  3. A long, hard, critical job you hand off? Extra high.
  4. Anything else: Medium.

Your answers

  • Switch to <level>
  • Switch, and auto-adjust from now (auto mode: no more questions)
  • Keep <current level>

If the pick matches your current level, nothing appears.

After a switch

A line above the prompt says "Effort set to Low (was High)", and an orange Effort label shows at the bottom of the chat. The effort menu beside the model name does not move, so read the orange label.

Commands

/effort-optimizer
/effort-optimizer auto | suggest
/effort-optimizer on | off
NOTE: Each check is one short model call at low effort. Slash commands are never checked. A third-party mod by Ben AI (benai.co). It is not part of this repository: get it from the original publication.

Side Chat Advisor

PurposeKeep quick, unrelated questions out of your main conversation, so Claude keeps its focus and the chat does not fill with side topics.

When it appears

  • Short lookups and tangents: "btw...", "what is...", "define...", "what is the difference between...".
  • Not for questions about the work in hand, code or file paths, or very early in a chat.

What you see

A toast and a row above the prompt: "Open a Side Chat in Split View". It never blocks your prompt.

Try it

After a few messages: btw, what is the difference between a lump sum and a schedule of rates contract?

Commands

/sidechat-advisor status
/sidechat-advisor on | off

Sensitivity and the cooldown are in /plugin configure.

NOTE: It only suggests. You open the Side Chat yourself.

Long Session Kit

PurposeSee how full a long conversation is, and carry on in a fresh one without losing what was decided. It writes a handoff note automatically, so nothing depends on you remembering.

The band

A row under the prompt: context used, size, and when the next handoff will happen. It turns amber near the limit and red past it.

A handoff note is written when

  • Context reaches 50%.
  • Context reaches 70%: another note is written and you are advised to compact.
  • You have been idle for 30 minutes.
  • The prompt cache has 10 minutes left (with the defaults, the idle rule fires first).

Short chats (under 3 prompts) are skipped. At 70% a message suggests /compact or carrying on in a new chat; it never compacts for you.

Where notes go

At the top level of the folder your session is linked to, as handoff-<date>.md and LATEST.md. Each note is marked as possibly containing confidential information, and costs one background model call.

If that folder is a git repository, add handoff-*.md and LATEST.md to its .gitignore so they are never committed.

Choose another folder

Type /lsk folder and pick, or type a full folder path. The choice is remembered for that project.

Commands

/lsk now | status | on | off
/lsk folder
/lsk folder reset
/lsk threshold 60
/lsk second 70 | off
/lsk resume

While a clickable question is open, the band area is taken over and the figure moves to the status line.

Ribbon (fork)

PurposeKnow how much of your usage allowance is left and whether your next message will be cheap or full price, so usage never surprises you.

What it shows

  • 7D and 5H: how much of your weekly and five-hour allowance is left, and when each resets.
  • WARM: the conversation is still cached, so the next message is cheaper. COLD: the cache has expired and the whole chat is paid for again.
  • Show opens a card with an estimated cost per model for your next message.

How to use it

If it says COLD and you have a long chat, expect the next message to cost more. Costs are estimates, not a bill.

About this version

A fork of the public Ribbon mod by Jay E | RoboNuggets (MIT licence). It follows your Claude colours, so it reads in light or dark mode. The plugin is named ribbon-wdc. Install it or the original, not both.

Savvy Progress

PurposeSee what helper agents are doing while a big job runs: which are working, how far along they are and a rough cost, instead of waiting without feedback.

What it shows

  • An agents panel, opened with /agents-info, listing running, finished and planned subagents with model, progress, context and estimated cost.
  • A progress bar above the prompt, but only for work run with the savvy-flow skill.

How it fits

The Subagent Advisor opens the panel for you after you choose subagents. You can also open it yourself at any time.

Commands

/agents-info

About this mod

Made by johnnyvizz (MIT licence) and used here unmodified. Cost figures are rough estimates from a built-in price table, not a bill.

Commands Pane

PurposeFind the right slash command without having to remember its name. Every available command is listed in one panel, grouped by what it does, with a one-line description, so you open only the group you need.

How to use

  1. Type /commands. A panel opens at the side of the chat.
  2. Click a group heading to open or close it.
  3. Click Refresh after installing a plugin, to pick up its new commands.
  4. Type /commands again to close it.

The groups

  • Session and conversation, Context and memory, Review and quality, Config and setup: Claude Code's built-in commands.
  • Skills and plugins: one sub-group per plugin, such as these mods.
  • Your own commands, MCP prompts and Other.

Each heading shows how many commands it holds. The panel remembers which groups you left open.

Commands

/commands
/commands refresh
/commands text

/commands text prints the same list in the chat, for when you want it as plain text.

NOTE: The commands are read live from your own setup, so the list differs between PCs. The panel sits at the side of the window, not in the left-hand session list. Long descriptions are shortened.
